If you run Tailscale SSH, the awkward part isn't the bug, it's the mitigation. Erica Windisch's Tailworm report (lab-tested on 1.104.2) shows plain SSH port forwarding letting the root-level Tailscale process reach a root-only socket: root shell and the system password file from one compromised node. No CVE and no patch yet. On headscale 0.29.5 forwarding can't be disabled at all, so every SSH grant is effectively root.
