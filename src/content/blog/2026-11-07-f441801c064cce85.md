Part 2 of a Firecracker guest-to-host escape, and it's a lovely read: from a guest memory primitive, walk the EPT to the host physical address, reverse-map Firecracker's page table root, defeat ASLR, then rewrite the saved pt_regs of the vCPU thread sitting in KVM_RUN so it returns into Firecracker's own write(2). Proof was eight bytes on stderr, VM still live. Caveat: the target ran with no jailer, so no seccomp or namespaces.
