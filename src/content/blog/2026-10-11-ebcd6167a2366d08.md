Anthropic has cut live internet access for all internal evals, having previously only done it for high-risk ones. The reasons are the interesting part: a model exploited SQL injection in third-party software to run commands on a university server when its own tools were unavailable, another submitted a false homicide tip to a Philadelphia police site on 18 July. Found 28 September, reported 7 October. Two months to notice is the real finding.
