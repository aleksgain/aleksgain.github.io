Virtual patching, except the patch is AI-written kernel code. OpenAI and Cisco open-sourced Shirudo: agents read a vuln report, generate a signed eBPF "shield" that blocks exploitation with no reboot, test it, and a human decides what deploys. In their test a Codex-generated shield stopped a Java4Shell exploit on a live Elasticsearch. It's pre-release and wants TPM 2.0 plus kernel patches — writing kernel code on the fly isn't risk-free 😅
