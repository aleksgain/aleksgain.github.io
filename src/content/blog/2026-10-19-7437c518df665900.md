Google dropped its own Pytype for Pyrefly, the Rust type checker Meta open-sourced. Internal numbers: ~10x faster, incremental rebuild latency down up to 98%, peak compute for Python type checking down more than 80%. The root cause is the interesting bit — Pytype analysed compiled bytecode, which shifts between Python releases, so keeping up with new typing PEPs got painful. Analyse the AST, not the artifact.
