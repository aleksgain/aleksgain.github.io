The anti-CSRF library is the pre-auth RCE. Idunno.AntiCsrf (CVE-2026-131914, CVSS 9.3) deserializes CSRF token data with an unkeyed ObjectStateFormatter and verifies no MAC, so a single unauthenticated POST executes code inside w3wp.exe. Mandiant has seen it exploited in the wild. The project hasn't been updated since December 2008, so there is no patch and won't be. Worth grepping Web.config and bin/ for AntiCsrfModule today.
