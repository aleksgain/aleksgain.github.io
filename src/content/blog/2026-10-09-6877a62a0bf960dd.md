Shai-Hulud is back, and this one reads your AI tooling. The malicious tensorlake 0.5.144 on npm grabbed npm and GitHub tokens, AWS keys, Vault secrets and SSH keys, plus the config and MCP files for Claude, Cursor, Kiro, Windsurf and Zed. Worst bit: a PowerShell watcher polls the stolen GitHub token, and when you revoke it, it runs an attacker-supplied handler. Revocation is now a trigger, not a fix.
