"Deprecated" and "gone" are very different planning problems. WSUS has been deprecated since September 2024; Microsoft now confirms the role is removed outright in Windows Server 2028, along with VBScript, WMIC and WINS. Server 2025 keeps WSUS for its full lifecycle and can still patch 2028 machines, so there's runway. Intune and Autopatch for clients, Azure Update Manager for servers. Disconnected environments? Microsoft will "share more" 😅
