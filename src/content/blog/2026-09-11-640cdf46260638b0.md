Copy-paste from the quickstart, ship to prod. Wiz found 294 of ~3,000 internet-facing LiteLLM gateways still accepting "sk-1234", the example master key from the docs. That key exposes every stored provider credential and every prompt, and can be a path to the underlying cloud account. The fix takes a minute: set a long random master key, upgrade, and lock down egress and IAM.
