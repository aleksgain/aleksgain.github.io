A heap overflow that has been sitting in nfsd since kernel 3.16 in 2014. CVE-2026-99362 lets a remote, unprivileged attacker overrun the buffer, read kernel memory to defeat KASLR, plant a callback in freed memory, and then just close the NFS connection — at which point the kernel runs their command as root. Fixed in 6.12.117, 6.18.61 and 7.3.2, no exploitation reported yet. If port 2049 doesn't need to face the internet, today is the day.
