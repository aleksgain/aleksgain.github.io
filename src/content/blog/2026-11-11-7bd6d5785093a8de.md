`git clone --recursive` on an untrusted repo can run code on your machine. CVE-2026-111760 is an integer truncation in index handling: a too-long path validates under one name and is written under a shorter one, so a submodule's .git file becomes a symlink into a directory holding malicious hooks. Six CVEs, fixed in 2.56.1 with backports down to 2.50.2. Your CI runners clone untrusted code all day — start there.
