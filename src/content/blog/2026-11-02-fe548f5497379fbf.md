Finally some numbers instead of vibes on "which framework is better for agents". Nolan Lawson had Opus 5.5 build the same Pokémon app 12 ways: Hono+htmx was cheapest at $2.67 a run and ~1,370 lines, Angular dearest at $4.97 and 9.76M tokens — about 2.3x the tokens for the same app. Astro shipped 0 KiB of JS, Next.js 142. He's upfront it's one small app with noisy runs, which is more honesty than most framework benchmarks manage.
