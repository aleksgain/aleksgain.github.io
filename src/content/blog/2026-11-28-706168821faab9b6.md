Four HTTP requests from a cold, unauthenticated session, and the box is yours. The 4HTTP2SHELL PoC against Cacti 1.2.31 — the current release — starts by writing a non-numeric string into preview_graphs_per_page, which Cacti never validates, then fires it as second-order SQLi when graph_view.php loads with default filters. Then graph_realtime.php hands a poller-table command to popen(). No patch yet. Check whether your guest account is on.
