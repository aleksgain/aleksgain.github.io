Patch Brotli, and not just in Node. CVE-2026-111497 is an out-of-bounds write in Google's Brotli decoder, CVSS 9.2: one unchecked return value and a crafted compressed stream corrupts memory. It reaches Python (requests, httpx, aiohttp), Bun, Envoy, Istio and bundled curl. The catch: as of Oct 23 pip-audit and Dependabot still didn't map the CVE to the PyPI packages, so a clean scan proves nothing. Fix is Brotli 1.2.1.
