AWS now ships its own local emulator: Rust, HTTPS on 127.0.0.1:9297, point AWS_ENDPOINT_URL at it and your code doesn't change. The part worth arguing about is who maintains it — agents find API gaps and file issues, other agents implement the fixes, a separate security agent reviews them adversarially. Per-service fidelity ships as a "k of n" score, IAM isn't really evaluated, so passing locally doesn't mean AWS will allow it.
