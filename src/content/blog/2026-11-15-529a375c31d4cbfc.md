Google Cloud finally lets you pin a Compute Engine API version per request: immutable date-stamped snapshots like 2026-09-01, picked with an X-Goog-Api-Version header. /v1 is unchanged with no EOL date, so nothing breaks today. Check the behaviour notes first — in dated versions AggregatedList returns partial results by default instead of failing on one bad zone, and errors arrive as structured ErrorInfo. Azure has required this since launch 😄
