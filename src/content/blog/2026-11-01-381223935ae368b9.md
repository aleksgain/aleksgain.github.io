A shared ChatGPT link was enough. Parameter found that MathLive's postMessage listener on chatgpt.com accepted messages from any origin and dropped unsanitized HTML into the page; an unsandboxed srcdoc iframe then inherited the chatgpt.com origin. CSP blocked inline script, so they bounced off an allow-listed YouTube JSONP endpoint and read private conversations ~4.5s after load. Fixed 26 October. Bounty: $5,000 😅
