The former GitHub CEO's answer to agent-written code is to throw out the pull request. Entire replaces the PR timeline — which Dohmke calls "an audit log that only the agent reads" — with Trails that can span repos, and runs an eval agent in a sandbox on every push, scoring code quality, security and "slop". Claimed pushes up to 89x faster than GitHub. Vendor number, sure, but a slop score as a merge gate will get copied.
