Turns out coding agents are a source control scaling problem. OpenAI has been running a new Git backend called Pando since April: close to a petabyte of Git data served per day, median push latency down nearly 80%, and over 99% hit rate on its pack-delivery cache. The trick is dropping the repository-wide snapshot so updates to unrelated branches stop serialising. Client and protocol stay plain Git, which is the part I like — no new VCS to learn.
