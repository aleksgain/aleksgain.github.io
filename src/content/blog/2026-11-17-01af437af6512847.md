Windows 11 apparently keeps a note of which coding agent you use. A researcher traced MissionControlAggregator.dll inside the DiagTrack service matching process names — copilot.exe, claude.exe, codex.exe, cursor.exe, plus node, python and gcc — then packing the hits into a bitmap uploaded when optional diagnostics are on. It's category bits, not prompts or code. Renaming a copy of cmd.exe to codex.exe was enough to register as Codex 😅
