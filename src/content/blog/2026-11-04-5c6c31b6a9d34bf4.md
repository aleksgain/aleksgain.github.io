CVSS 10.0, no authentication needed: CVE-2026-58115 lets anyone reach a Node-RED instance running without adminAuth and push a flow that runs system commands. VulnCheck saw the first successful exploitation on October 30, then 15 more attacks from the same IP by November 1, dropping a Linux bot and persistent webshells. Siemens flagged it on August 11. If someone spun up Node-RED "just for a quick integration," go look today.
