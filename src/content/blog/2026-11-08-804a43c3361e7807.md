“Yes, and don't ask again” turns out to be a security decision. Apiiro found 1,122 copies of .claude/settings.local.json on public GitHub holding 1,379 secrets — 379 database passwords, 43 SSH logins, 23 AWS keys. Claude Code adds that file to your global git excludes, never to the repo's own .gitignore. In half of those repos the secret has been sitting on the default branch for 217+ days. Approve patterns, not exact commands.
