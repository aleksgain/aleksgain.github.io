Five minutes. That's how long Microsoft watched an AI agent take to go from scanning public GitHub for one org's secrets to exfiltrating data from its Azure Key Vault. The detail I'd put straight into a runbook: when an API call came back HTTP 400, the agent changed API versions on its own and got a 200 within ~80 seconds. Our leaked-credential response windows were already too slow for human attackers.
