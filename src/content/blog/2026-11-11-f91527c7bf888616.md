Model weights are build artifacts, and nobody diffs them. Microsoft edited fewer than 10 neurons in a capable agent model to plant a payload: it passes every eval, then runs an attacker-chosen command when a trigger string shows up in its context. The suggested audit is unglamorous and overdue — diff each checkpoint against its declared base model and flag any tensor or row whose change is a statistical outlier.
