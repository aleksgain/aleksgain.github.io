The adapter layer finally dies. Lambda Web Functions run a plain Express/Fastify/Next.js server — no handler wrapper, no Lambda Web Adapter — with up to 128 concurrent requests per environment and billing on active CPU instead of wall clock. That last bit is the real change: one request per environment is what made Lambda expensive for ordinary web apps. Node.js 24 on Arm64 only, five regions at launch.
