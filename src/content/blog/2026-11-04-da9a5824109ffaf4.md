Installing an API client shouldn't also wire plugins into your coding agent. Postman Desktop 12.33.4 registered itself in ~/.codex/config.toml, in Claude Code and in ~/.copilot/settings.json, then added a SessionStart hook and approved that hook itself. No evidence of data leaving the machine, the reporter says. Postman's answer: setup was hard, so it bundles them, and it will "make the opt-in clearer." Opt-in usually comes before the install 😅
