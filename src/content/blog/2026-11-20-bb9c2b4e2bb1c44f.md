A useful counterpoint to "just let the agent write it": Adam Tornhill's numbers say healthy code needs 40-45% fewer tokens, which makes code quality a line item on your inference bill. A study of 1,000+ open source projects saw early velocity gains wiped out after about two months as complexity climbed. In low-health code an agent fixes roughly 50% of the issues; hand it code-health data via MCP and that goes to 90-100%. Context beats vibes.
