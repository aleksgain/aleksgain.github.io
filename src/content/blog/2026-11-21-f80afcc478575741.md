Guest-to-host memory access on AMD, and nested virtualization is on by default in kvm_amd. CVE-2026-99312 let a researcher read roughly 127 GB of host RAM from a DigitalOcean Droplet, and on his own bare metal, write 32 bytes into a live host kernel page. Root cause: the 2022 fix for CVE-2022-3344 missed one path, so the stale pointer sat there for nearly four years. Fixed in 6.18.64 and 6.12.118 — check /sys/module/kvm_amd/parameters/nested.
