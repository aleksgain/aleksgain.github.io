$200,000 in bounties for one architectural decision. Binary Security chained five elevation-of-privilege bugs in Azure API Connections into full cross-tenant compromise: read a stranger's Key Vault secret, write rows into their Azure SQL. The part worth reading is the remediation trail. MSRC blocked paths and undocumented endpoints instead of the "any connection can act on any other" design, and each time the researcher found the way back in.
