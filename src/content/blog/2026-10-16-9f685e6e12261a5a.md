Two Tempo 3.1 changes worth knowing if you run it yourself. tempo-cli redact now takes a TraceQL query instead of a list of trace IDs, with --dry-run to count matches first - that's the difference between "we can remove the leaked field" and "send us the trace IDs". And the Kafka client finally speaks TLS/mTLS and SCRAM; 3.0 offered SASL PLAIN, unencrypted. Redaction can't be undone, so check twice.
