The useful part of Google's Data Agent Kit going GA isn't the 37 skills or the 15+ services - it's the admission that a skill is advice, not a control. The data-loss-prevention skill asks the agent to get consent before DROP TABLE or a DELETE without WHERE. What actually stops it is an IAM deny policy on mcp.googleapis.com/tools.call where tool.isReadOnly is false. Blocked tools still appear in tools/list.
