Your agent's working directory is part of your attack surface now. Forever Security found a malicious AGENTS.md in a customer's ~/Downloads telling the coding agent to install a rogue npm package - Codex obeyed in 90% of their tests, and a CLAUDE.md variant leaked Claude Code's OAuth token about half the time. There's nothing for OpenAI or Anthropic to patch here: just stop launching agents in a folder any website can write to.
