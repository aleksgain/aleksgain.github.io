Right now most agent stacks drag a whole Chromium around just to read a web page. Cloudflare has open-sourced Kitesurf under Apache 2.0: a stateless browser engine written in Rust, compiled to WebAssembly, running on Workers with no container at all — and it speaks Chrome DevTools Protocol, so Puppeteer connects as-is. Still experimental, and page JavaScript falls back to Boa only as a last resort.
