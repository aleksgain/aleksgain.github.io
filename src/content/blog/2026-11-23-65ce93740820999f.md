Lambda can now do GPU inference: G-series instances on Managed Instances, up to 48 concurrent invocations sharing one copy of the model in GPU memory. A community test ran Gemma 4 E2B on a g6.2xlarge with vLLM — about 130 tokens/s for a single request, 3,400-3,600 at 48. The catch is startup: one publish-to-active took 484 seconds, so this is not scale-to-zero serverless. Event Functions only for now.
