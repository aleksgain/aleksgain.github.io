If you ship anything that touches OpenPGP keys, go check your GPGME version. CVE-2026-129975 is a double free from a key with a very long user ID: the buffer gets realloc'd but the new pointer is only written back at the end, so an early return leaves the context holding freed memory. Everything below 2.3.0 is affected — mail clients, Samba, Flatpak, Gpg4win. GnuPG says exfiltration is on the table and RCE "can't be ruled out". Fix is 2.3.1.
