If someone opened a PR titled "docs: dependency audit notes" on your repo this week, treat that account as compromised. Aikido counted 4,837 hijacked GitHub accounts probing 61,764 repositories since 10 November, with the stealer confirmed running in 1,800+. No Action or registry was breached — just stolen tokens, write access and a 1,500-line script that mints OIDC cloud sessions and widens AWS trust policies.
