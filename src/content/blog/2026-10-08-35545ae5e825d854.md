If you run vLLM with LMCache, go check what your multiprocess port is bound to. JFrog found an unauthenticated RCE (CVE-2026-105192, rated 9.8) in versions 0.3.9 through 0.5.5: the ZeroMQ socket has no authentication and one message type gets unpickled before its type is checked. There is no fixed release yet, the official container images run as root, and the project's own example Kubernetes deployment listens on every interface.
