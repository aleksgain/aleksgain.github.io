The AI coding numbers everyone quotes are the easy half. A Harvard study across 718 firms, ~700,000 workers and ~300M work events found agents lift lines of code 30% and PRs 23%, but resolved issues only 12% - while average PR review time rose 49%, comments per PR 53%, and the share of PRs needing changes doubled. Engineers write code 30-40% of the time. Speeding that up just moves the queue downstream.
