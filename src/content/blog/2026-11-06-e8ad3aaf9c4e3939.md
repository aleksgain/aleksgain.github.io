The number that explains GitHub's storage rewrite: one repository went from an average 44M daily requests in March to 181M in May. Today's busiest repos peak at dozens of writes per second; the new backend sustained 7,200 pushes/sec to a single repo in testing with 5,000 concurrent agents. Packs live in Azure Blob, refs in a replicated log called Ref-CAS. Agents aren't just writing code now, they're rewriting storage architecture.
