A budget that actually stops spending, finally. Google Cloud spend caps hit GA on 10 November: reach the monthly number and new requests to that service in that project are blocked, with alerts at 50/80/100%. Enforcement runs off estimated live costs instead of settled billing, so it bites within minutes, not hours. Catch: only Gemini API, Gemini Enterprise Agent Platform, Cloud Run and Cloud Run functions.
