Sandboxing coding agents has been everyone's homemade shell script so far, so MXC reaching GA is worth a look: one JSON policy declares the files and hosts an agent may touch, and the OS enforces it outside the agent's control. Four backends, from AppContainer/Seatbelt/Bubblewrap processes up to an experimental MicroVM. Copilot, Codex, OpenClaw and Replit already support it. Start in Learning mode, which logs what the policy would have blocked.
