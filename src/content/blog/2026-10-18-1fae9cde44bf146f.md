Your npm audit doesn't read compiled binaries. imgdecode ships nine lines of JavaScript that load a Windows DLL, which pulls banner.jpg from a GitHub repo, decrypts shellcode with a hardcoded key and injects it into dllhost.exe. It even checks whether it's running in a developer's terminal first. 979 downloads, and SafeDep found it still live on npm. Native addons are a scanning blind spot worth a second look.
