"Is anyone still calling this method?" is the question that keeps deprecated APIs alive for years. Netflix built Quasar to answer it with evidence: SCIP indexes submitted during CI builds, stored as Parquet in S3 and queried through Athena, so a PR can tell you a method removal touches 137 repos across three library versions. Good that the post names the blind spot: no indexed reference doesn't prove nobody calls it.
