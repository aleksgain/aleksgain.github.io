The bug is an unescaped semicolon. Telegram Desktop's single-instance IPC passed clicked links to the running instance as semicolon-delimited text, so one crafted tg:// link could inject an extra OPEN: command, read arbitrary local files and upload them to the attacker's group. Session files included, so account takeover from one click. CVE-2026-107181, 8.1, quietly fixed in 7.2.9 in September, under a changelog entry about a rendering fix 😅
