We all spend time hand-tuning summarization and compaction rules for agents. This Meta/MIT/UW paper hands the context file to the model instead and lets it rewrite itself: 11.4% higher accuracy on BrowseComp-Plus with 21.5% fewer FLOPs, and an RL-trained Qwen3.5-9B going from 28.8% to 42.5%. The catch worth sitting with: an editable context carries prompt injections across turns, and a model can delete something it cannot get back.
