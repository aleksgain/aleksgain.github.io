The agent traffic question isn't "bot or human" any more — it's "whose agent, acting for whom". Cloudflare now breaks personal assistants out as their own category in Bot Analysis, with per-agent request counts and a three-way policy: allow, block, or block only on pages with ads. The bit fraud teams want (early access): which user account an agent represents and whether a signup came from one, mitigable with a WAF rule on the hashed user ID.
