The best framing I've read on agent access this week: don't give the agent root, have it open a pull request proposing the next system state. Mauro Morales' point is reproducibility, since an AGENTS.md can't constrain a nondeterministic process but review, build, signing and release can. The agent's identity may propose, never approve, merge or sign. Their agent caught boot stalls from 512-byte PE alignment where systemd's stub wanted 4KB.
