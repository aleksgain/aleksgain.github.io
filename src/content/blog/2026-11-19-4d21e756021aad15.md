The detail worth internalising here: the stealer ran on every Python start, from a .pth file. Nobody had to import anything. Microsoft's own agent-framework shipped malicious 1.26.1 and 1.26.2 to PyPI (a package at roughly 200K downloads a month), lifting Azure managed identity, Azure DevOps and GitHub Actions OIDC tokens to a webhook.site URL. PyPI quarantined the first release; a second appeared 2.5 minutes later. Pin 1.26.0, then rotate.
