Patch window, today. CVE-2026-119618 is a race condition in mod_http2's assign_headers(): heap corruption, no auth, code execution as the web server user. Everything from httpd 2.4.55 to 2.4.70 with HTTP/2 enabled is in scope, and Wiz sees vulnerable resources in 64% of cloud environments, 51% of them publicly exposed. No public exploit yet. Fix is 2.4.71; Protocols http/1.1 buys you a weekend.
