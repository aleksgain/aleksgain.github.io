CVE-2026-21589, CVSS 9.3: unauthenticated path traversal that reads files out of the web application root across eight Atlassian Data Center products — Jira Software, Jira Service Management, Confluence, Bitbucket, Bamboo, Crowd, Crucible and Fisheye. You have to know the exact filename because you can't list the directory, which is thin comfort when every install puts its config in the same place. Cloud is already patched; self-hosted is yours.
