That "Yes, and don't ask again" button saves the entire command as a permanent rule — including any secret you typed into it. Apiiro found 1,122 public settings.local.json files holding real credentials; GitGuardian counted 31,088 secrets in them, 5,343 still valid. Claude Code adds the file to your global gitignore, never the repo's own. Worth a `git rm --cached` and a rotation pass today.
