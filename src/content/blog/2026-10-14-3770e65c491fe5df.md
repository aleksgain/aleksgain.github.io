Trusted publishing trusted the wrong thing. npm identified the source repo by its "owner/repo" slug instead of GitHub's immutable numeric ID, so claiming an abandoned or renamed slug was enough to mint a publish token for a package you don't own. Bloom Security found 1,500+ packages exposed this way, 10M+ downloads between them. Unused bindings now expire after 48 hours — go audit yours.
