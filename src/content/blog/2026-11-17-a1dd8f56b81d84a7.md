One for the calendar: Windows Server 2016 gets its last security update in January 2027 and reaches end of support on 13 January. After that it's Extended Security Updates or nothing — and 2016 is exactly the vintage still quietly running a file share or a licence server nobody owns any more. Mainstream support ended in January 2022, so this had a five-year run-up. Server 2025 is the target, with a free 180-day trial to test against.
